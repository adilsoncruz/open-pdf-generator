PDF Generator Library

A Kotlin/Java library for PDF generation from JSON templates using OpenPDF.

Installation

Gradle (Kotlin DSL)

repositories {
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.adilsoncruz:open-pdf-generator:1.0.0")
}

Maven

<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>com.github.adilsoncruz</groupId>
        <artifactId>open-pdf-generator</artifactId>
        <version>1.0.0</version>
    </dependency>
</dependencies>

Quick Example

import com.pdfgenerator.PDFGenerator
import com.pdfgenerator.template.Template
import java.io.File

fun main() {
    val templateJson = """
    {
      "version": "1.0",
      "pageSettings": {
        "size": "A4",
        "orientation": "portrait",
        "margins": {"top": 30, "right": 30, "bottom": 30, "left": 30}
      },
      "pageElements": [
        {
          "type": "text",
          "id": "title",
          "x": 50,
          "y": 50,
          "value": "My First PDF!",
          "style": {
            "fontSize": 24,
            "fontWeight": "bold"
          }
        }
      ]
    }
    """
    
    val template = Template.fromString(templateJson)
    val generator = PDFGenerator()
    generator.generate(template, emptyMap(), File("output.pdf"))
    
    println("PDF generated successfully!")
}

Features

  • Ultra Lightweight - Only 5.1 MB Fat JAR
  • Performance - Fast cold start
  • JSON Templates - Simple to use
  • Data Binding - Dynamic data
  • Paginated Tables - Automatic pagination
  • Fixed Headers - On all pages
  • QR Code and Barcode - Native support
  • Open Source - LGPLv3 License

Supported Elements

Element Description
Text Static or dynamic text
Image Images from URL, file, or base64
Table Tables with automatic pagination
Rectangle Rectangles for backgrounds
Line Horizontal, vertical, or diagonal lines
Barcode QR Code and barcodes
Conditional Conditional rendering
Loop Element repetition
