Get started quickly

Everything you need to know to create your first template

01

Installation

  1. Download the .dmg file
  2. Open the downloaded file
  3. Drag PDF Template Editor to Applications
  4. Launch from Applications folder
Note: On first launch, you may need to allow the app in System Preferences → Security & Privacy.
02

Creating a Template

  1. Click New to create a blank template
  2. Select a section (Header, Body, or Footer)
  3. Add elements from the sidebar
  4. Position elements by dragging on the canvas
  5. Edit properties in the right panel
03

Data Binding

Use double curly braces to bind data:

{{customer.name}} {{invoice.total}} {{pageNumber}}

Click Test Data to add sample JSON data and see the preview update in real-time.

04

Generating PDFs

  1. Ensure your template is saved
  2. Add test data in the Data Panel
  3. Click Generate PDF
  4. Wait for the Java library to process
  5. Choose to open the generated PDF

Advanced Features

🔄 Loop Element

Iterate over arrays of data to create repeated content. Perfect for invoice line items, product lists, and more.

dataBinding: "items" Child elements use: name, price, qty
  • Add child elements inside the loop (Text, Image, Rectangle, etc.)
  • Automatic pagination when content exceeds page
  • Configurable item spacing
  • Drag-and-drop reordering of children

📍 Position Mode

Control how elements are positioned relative to other content.

  • ABSOLUTE (default): Fixed position on the page
  • RELATIVE: Position based on content above

Use RELATIVE mode for elements that should flow after dynamic content like loops or multiline text.

📝 Multiline Text Overflow

Control how multiline text behaves when it exceeds the defined height.

  • visible: Content can overflow the box
  • hidden: Content is clipped at the defined height
  • auto: Height adjusts to fit all content

Use overflow: auto when you have a RELATIVE element below that should position after all the text content.
