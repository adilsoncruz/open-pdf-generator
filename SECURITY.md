# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest major and minor versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Open PDF Generator team takes the security of our software seriously. If you believe you have found a security vulnerability in any part of this repository (Core engine, CLI, or Desktop Editor), please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

1. Send an email to **[adilsoncruz.ac@gmail.com](mailto:adilsoncruz.ac@gmail.com)** with the subject line `[SECURITY] Potential vulnerability in Open PDF Generator`.
2. Include in your report:
   - Type of issue (e.g., buffer overflow, XXE, SSRF, arbitrary code execution, path traversal)
   - The affected component(s): Core Engine, CLI, Desktop Editor, or Documentation
   - Step-by-step instructions or minimal reproducible template JSON to reproduce the issue
   - Proof-of-concept (PoC) code or sample template, if available
   - Impact of the issue, including how an attacker could exploit it

### Response Timeline

- **Initial acknowledgment**: Within 48 hours.
- **Triage and confirmation**: Within 7 business days.
- **Patch and coordinated disclosure**: As quickly as possible depending on severity, typically within 30 days.

We kindly ask you to give us reasonable time to investigate and mitigate the issue before disclosing it publicly.
